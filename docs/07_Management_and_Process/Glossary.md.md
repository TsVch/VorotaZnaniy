## 📖 A

**Access Grant**  
A database record explicitly linking a specific User (Viewer) to a specific Document, granting them permission to view it. May include an expiration date.  
*Related: [Database Design](../03_Architecture_and_Design/Database_Design.md), [Authorization](../04_Security_and_Access/Authorization.md)*

**ADR (Architecture Decision Record)**  
A short text document capturing an important architectural decision made along with its context and consequences.  
*Related: [Architecture Decision Records](./ADR/)*

**AI Worker**  
The isolated Python/FastAPI microservice responsible for heavy background tasks: document parsing, text chunking, embedding generation, and RAG (Retrieval-Augmented Generation) query processing.  
*Related: [Backend Architecture](../03_Architecture_and_Design/Backend_Architecture.md), [ADR-002](./ADR/002_Isolated_AI_Worker.md)*

---

## 📖 B

**Blueprint**  
The complete, living documentation of the project. It is the Single Source of Truth. No code implementation may begin or be accepted if it contradicts the Blueprint.  
*Related: [README](../README.md), [INDEX](../INDEX.md)*

**BullMQ**  
A premium, Redis-based message queue and job processor for Node.js, used to decouple the core API from the AI Worker.  
*Related: [Backend Architecture](../03_Architecture_and_Design/Backend_Architecture.md)*

---

## 📖 C

**Canvas Rendering**  
The technique of drawing document pages as images onto an HTML5 `<canvas>` element, rather than using native browser PDF viewers (`<iframe>` or `<object>`). This is a core DRM mechanism to prevent direct file downloads.  
*Related: [Frontend Architecture](../03_Architecture_and_Design/Frontend_Architecture.md), [Security Requirements](../04_Security_and_Access/Security_Requirements.md)*

**Concurrent Session Limit**  
A DRM enforcement rule restricting the number of simultaneous active viewing sessions a single user can have for a specific document (e.g., max 2 devices).  
*Related: [Security Requirements](../04_Security_and_Access/Security_Requirements.md)*

---

## 📖 D

**DRM (Digital Rights Management)**  
A set of access control technologies and business logic used to restrict the use of proprietary hardware and copyrighted works. In this project, it refers to watermarking, session limits, and canvas rendering.  
*Related: [Security Requirements](../04_Security_and_Access/Security_Requirements.md)*

**DoD (Definition of Done)**  
The non-negotiable checklist of criteria that must be met for any task to be considered complete and accepted by the CTO.  
*Related: [Definition of Done](./Definition_of_Done.md)*

---

## 📖 E

**Embedding**  
A numerical vector representation of text (e.g., a chunk of a document) generated by an AI model (like OpenAI's `text-embedding-3-small`). Used for semantic similarity search in the RAG pipeline.  
*Related: [Database Design](../03_Architecture_and_Design/Database_Design.md), [Integrations](../05_Infrastructure_and_Operations/Integrations.md)*

---

## 📖 F

**Freebuff**  
The designated Implementation AI agent. Freebuff is responsible for writing code, debugging, testing, and refactoring based *strictly* on the Task Packages provided by the CTO. Freebuff does not make architectural decisions.  
*Related: [Task Package Template](./Task_Package_Template.md)*

---

## 📖 I

**IDOR (Insecure Direct Object Reference)**  
A security vulnerability where an application provides direct access to objects based on user-supplied input, allowing attackers to access data belonging to other users. Strictly prevented via Workspace/Document ownership checks.  
*Related: [Security Requirements](../04_Security_and_Access/Security_Requirements.md), [Authorization](../04_Security_and_Access/Authorization.md)*

---

## 📖 M

**Magic Link**  
A passwordless authentication method where a user receives a single-use, time-limited URL via email to log in or claim access to a purchased document.  
*Related: [Authentication](../04_Security_and_Access/Authentication.md)*

**Modular Monolith**  
An architectural pattern where the application is built as a single deployable unit, but the code is strictly organized into independent, loosely coupled domain modules.  
*Related: [System Architecture](../03_Architecture_and_Design/System_Architecture.md), [ADR-001](./ADR/001_Modular_Monolith_over_Microservices.md)*

**MVP (Minimum Viable Product)**  
The smallest possible version of the product that delivers core value (secure document viewing, basic AI, Stripe integration) and can be released to early adopters.  
*Related: [MVP Scope](../02_Product_and_UX/MVP_Scope.md)*

---

## 📖 P

**Presigned URL**  
A time-limited, cryptographically signed URL that grants temporary permission to perform a specific action (e.g., `GET` or `PUT`) on a private object in S3/R2. The backend generates these; the frontend uses them directly.  
*Related: [API Contracts](../03_Architecture_and_Design/API_Contracts.md), [Security Requirements](../04_Security_and_Access/Security_Requirements.md)*

**`pgvector`**  
An open-source vector similarity search extension for PostgreSQL. Used to store and query document embeddings without needing a separate vector database.  
*Related: [Database Design](../03_Architecture_and_Design/Database_Design.md), [ADR-003](./ADR/003_PostgreSQL_with_pgvector.md)*

---

## 📖 R

**RAG (Retrieval-Augmented Generation)**  
An AI framework that retrieves relevant facts from an external knowledge base (our document embeddings) and passes them to a Large Language Model (LLM) to generate accurate, context-grounded answers.  
*Related: [Integrations](../05_Infrastructure_and_Operations/Integrations.md)*

**RBAC (Role-Based Access Control)**  
An authorization model where system access is granted to users based on their defined role (Admin, Creator, Viewer) within the system.  
*Related: [Authorization](../04_Security_and_Access/Authorization.md), [Roles and Permissions](../04_Security_and_Access/Roles_and_Permissions.md)*

---

## 📖 S

**Session Heartbeat**  
A lightweight, periodic API call (e.g., every 60 seconds) from the frontend viewer to the backend to prove the user is still actively viewing the document and to enforce concurrent session limits.  
*Related: [Frontend Architecture](../03_Architecture_and_Design/Frontend_Architecture.md), [Security Requirements](../04_Security_and_Access/Security_Requirements.md)*

**Single Source of Truth (SSOT)**  
The practice of structuring information models and associated data schemas such that every data element is mastered (or edited) in only one place. For this project, the `/docs` Blueprint is the SSOT.  
*Related: [README](../README.md)*

---

## 📖 W

**Watermarking**  
The process of overlaying user-identifying information (email, session ID, timestamp) onto the viewed document. In this project, it is dynamic, visible, and subtly shifts to deter screenshotting.  
*Related: [Frontend Architecture](../03_Architecture_and_Design/Frontend_Architecture.md), [Security Requirements](../04_Security_and_Access/Security_Requirements.md)*

**Workspace**  
An organizational unit within the platform owned by a Creator. It contains documents, analytics, and billing settings. Enforces multi-tenant isolation.  
*Related: [Database Design](../03_Architecture_and_Design/Database_Design.md), [Authorization](../04_Security_and_Access/Authorization.md)*

## 📌 Key Takeaways for Implementation (Freebuff)

1. **Use this Glossary**: When in doubt about the meaning of a term in a Task Package or Blueprint document, refer to this Glossary.
2. **Consistency**: Use these exact terms in code (variable names, comments, API payloads) and documentation. Do not invent synonyms (e.g., do not use "Tenant" when the Blueprint says "Workspace").
3. **Clarification**: If a term is used in a new context that is not defined here, request clarification from the CTO before implementation.
